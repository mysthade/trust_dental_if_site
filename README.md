# TRUST DENTAL — сайт стоматологічної клініки (Frontend)

Вебсайт приватної стоматологічної клініки **TRUST DENTAL** (м. Івано-Франківськ, вул. Галицька, 51а).
На поточному етапі реалізована **виключно клієнтська частина (суто фронтенд)** без активного бекенду та серверної бази даних.

## Стек і особливості
- **Технології**: чистий **HTML5**, **CSS3** і **vanilla JavaScript** (без фреймворків, збірників та зовнішніх CDN).
- **Теми оформлення**: світла й темна теми (`data-theme="light" | "dark"`), збереження вибору користувача в `localStorage` (`td-theme`) та підтримка View Transitions API.
- **Продуктивність і стабільність**: інлайн критичний CSS у `<head>`, самохостингові шрифти `Inter Variable` (`woff2`), оптимізовані зображення, плавне прогресивне завантаження без preloader і без зміщень макета (`CLS = 0`).
- **Доступність (A11y)**: семантична розмітка, клавіатурна навігація й focus-trap у меню та модальних вікнах, підтримка `prefers-reduced-motion` і `forced-colors`.

## Основні розділи сайту
- **Hero та показники клініки** — головний екран, швидкий перехід до запису/послуг, рейтинг і статистика.
- **Послуги та орієнтовна вартість (`#services`)** — 8 напрямків стоматології з розкривним переліком того, що входить у послугу, та швидким додаванням до калькулятора.
- **Переваги (`#advantages`)** — ключові принципи роботи клініки.
- **Попередній розрахунок вартості (`#calculator`)** — інтерактивний вибір процедур і кількості (зуби/щелепи) з підрахунком орієнтовної суми та передачею розрахунку у форму запису.
- **Команда фахівців (`#doctors`)** — картки лікарів (наразі заповнені слотами-заглушками до фінального наповнення даними клініки).
- **Приклади лікування (`#works`)** — карусель клінічних випадків у форматі «До / Після» з модальним лайтбоксом.
- **Фотогалерея клініки (`#gallery`)** — дві каруселі («Всередині» та «Зовні») з лайтбоксом (наразі з placeholder-макетами до додавання реальних фото).
- **Відгуки пацієнтів (`#reviews`)** — адаптивний слайдер і готовий адаптер `TD.reviewsSource` для майбутнього завантаження відгуків Google Business Profile через бекенд.
- **Запис та контакти (`#contacts`)** — форма запису на прийом із клієнтською валідацією, контакти клініки та вбудована карта Google Maps.
- **Мобільна навігація** — випадаюче меню з послідовною анімацією відкриття та фіксована нижня панель швидких дій.

## Структура проєкту
```text
├── index.html          # Основна HTML-розмітка, критичний CSS та SVG-спрайт
├── css/
│   └── style.css       # Стилі світлої/темної тем, компонентів, анімацій та адаптиву
├── js/
│   ├── data.js         # Єдине джерело даних window.TD і спільні утиліти
│   ├── theme.js        # Перемикання світлої/темної теми
│   ├── header.js       # Липка шапка, scroll-spy, мобільне меню та панель швидких дій
│   ├── effects.js      # Лічильники та прогресивний scroll-reveal
│   ├── render.js       # Безпечний DOM-рендер секцій, каруселей, лайтбоксів і форми
│   ├── calculator.js   # Логіка інтерактивного калькулятора вартості
│   └── main.js         # Ініціалізація модулів сторінки
├── fonts/              # Локальні шрифти Inter Variable (.woff2)
├── img/                # Зображення hero, іконки послуг, логотипи та макети
├── robots.txt          # Правила індексації
└── sitemap.xml         # Карта сайту
```

## Локальний запуск
Оскільки проєкт статичний, достатньо відкрити `index.html` у браузері або запустити будь-який локальний HTTP-сервер із кореня проєкту, наприклад:

```bash
python -m http.server 8000
```

Після запуску сайт буде доступний за адресою `http://localhost:8000/`.

## Подальший етап (бекенд і контент)
- Підключення серверних endpoint-ів у `js/data.js`:
  - `TD.APPOINTMENT_CONFIG.endpoint` — для надсилання заявок із форми запису на сервер / у CRM;
  - `TD.REVIEWS_META.endpoint` — для отримання відгуків із Google Places API через бекенд;
  - `TD.APPOINTMENT_CONFIG.privacyPolicyUrl` — посилання на сторінку політики конфіденційності.
- Заміна тимчасових макетів у блоках лікарів, клінічних робіт та фотогалереї на фінальні матеріали клініки.
